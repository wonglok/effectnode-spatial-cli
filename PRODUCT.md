# Product

## Register

product

## Platform

web

## Users

Real-time VFX artists and WebGPU/Three.js developers authoring node-based effects in a
browser-based studio. They iterate fast on materials and geometry, then ship effects to
other apps and teammates. Primary audience: the artist authoring inside the studio.
Secondary audience: the developer embedding exported `.enfx` files in their own runtime
via the SDK.

## Product Purpose

EffectNode FX Studio is a CLI-launched, browser-based authoring tool for real-time visual
effects. It exists to make an effect portable: author once with TSL node materials, Draco
geometry, and AVIF textures, then export a single `.enfx.zip` that runs anywhere via the
SDK. Success is an artist going from idea to a reusable, shareable effect without leaving
the tool.

## Positioning

The open, portable format for real-time visual effects — author in EffectNode, run
anywhere on WebGPU.

## Brand Personality

Precise, calm, capable. The tool should disappear into the task; confidence comes from
craft and speed, not decoration. Three words: focused, calm, modern.

## Anti-references

- Dreamy glassmorphism and animated aurora gradients (the 2023 AI-SaaS look) — no frosted
  cards, no drifting blobs, no gradient text.
- Marketing hero-metric layouts and identical icon-card grids.
- Tiny all-caps tracked eyebrows above every section.

## Design Principles

1. Tiffany is the accent, not the wallpaper — reserved for actions and active state.
2. The tool disappears into the task — standard affordances, familiar patterns, no invented
   controls.
3. Real content over decoration — every surface is a working state, not a styled placeholder.
4. One calm, legible system — a single sans family, crisp 1px borders, deliberate spacing.

## Accessibility & Inclusion

WCAG 2.1 AA. Reduced motion respected (no non-essential animation). Body text ≥4.5:1
contrast; keyboard-reachable controls; visible focus-visible rings.
